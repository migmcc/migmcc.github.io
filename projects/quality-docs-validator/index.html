Quality Docs Validator

Inspect potential inconsistencies between PFMEA and Control Plan workbooks with explicit, severity-classified findings.

Source and README ↗Technical reference ↗
PythonPFMEAControl Plan
Why it matters

The problem

PFMEA and Control Plan documents may appear complete on their own while disagreeing across operations, control methods, special characteristics and reaction plans.

How it works

The approach

The local Python CLI reads two XLSX files, matches normalized operations and performs six documented checks. Its findings are potential gaps requiring engineering judgment.

What it includes

  • Six explicit documented finding types
  • Severity-weighted score and human-readable verdict
  • Terminal, Markdown and JSON reports
  • Synthetic sample workbooks

Who it's for

Quality, manufacturing and supplier-quality engineers

Evidence / example

Examples of recorded findings

  1. CriticalOperation 20 — Missing reaction plan

    The source report flags a high-severity failure mode (S=9) without a reaction plan.

  2. CriticalOperation 30 — Missing control

    PFMEA failure mode(s) are present, but the Control Plan has no control method.

  3. WarningOperation 40 — Unmatched process step

    No corresponding Control Plan row was found.

Try the tool

Quick start

Commands adapted from the project's documented README. Run from the repository root after cloning it; consult the full README for prerequisites and platform-specific setup.

git clone https://github.com/migmcc/quality-docs-validator.git
cd quality-docs-validator
python -m pip install -e .
qdv pfmea-control-plan --pfmea examples/pfmea.xlsx --control-plan examples/control-plan.xlsx --out report.md
